# UI

## Palette de couleur
Palette — un fond encre plutôt que noir pur, avec un accent orange chaud qui fait écho à l'icône RSS historique (au lieu du bleu/violet SaaS habituel)
--bg #12151C
--surface #1A1E27
--border #262B36
--text #E8EAF0
--text-muted #8B93A7
--accent #FF7A33
--new #5FD98A

## Typo
Typo — une serif éditoriale pour les titres d'articles (effet "revue de presse" plutôt que dashboard), une sans-serif compacte pour l'UI/les métadonnées.

## Layout
Layout — plus de cartes uniformes à bordures/ombres identiques : une liste fluide séparée par des filets fins, plus proche d'un fil de lecture que d'un tableau de bord. Le panneau "Sources" devient une rangée de puces horizontales scrollables sous le header en mobile, et reste une colonne fixe à droite en desktop (bascule à ~960px). Header compact et sticky.
